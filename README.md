# Site Maxitec

Landing page institucional de alta conversão construída em Next.js, pronta para Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Publicar na Vercel

1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel, escolha **Add New > Project**.
3. Importe o repositório.
4. Framework detectado: **Next.js**.
5. Clique em **Deploy**.

O WhatsApp comercial está configurado como `5515997491884` em `app/page.js`.

## Conteúdo

- Maxivision Digital
- Estroboscópio LED
- Vídeos reais da operação
- Seção institucional
- Formulário que monta a mensagem e abre o WhatsApp
- Botões de WhatsApp em pontos estratégicos
- SEO e Open Graph básicos
- Layout responsivo para desktop, tablet e celular
